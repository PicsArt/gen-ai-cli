# gen-ai CLI — Documentation

A single terminal command to interact with Picsart's entire AI model catalog —
generate assets, explore models, validate payloads, and run batch jobs. Built on
top of the `@picsart/ai-sdk` package, which already provides the model registry,
workflow client, input validation, and pricing resolution. The CLI is called
**`gen-ai`**.

> New here? Start with the [installation + quickstart in the top-level README](../README.md),
> then the hands-on tutorial below. For the source-tree layout and layer rules,
> see [ARCHITECTURE.md](../ARCHITECTURE.md).
