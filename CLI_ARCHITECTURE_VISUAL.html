Import direction. Read the diagram top-to-bottom — top layers depend on lower ones, never the other way around. A command file in 05-shells can import anything below it; an infrastructure primitive cannot reach back up. The runtime pipeline does the opposite: a request flows down from the user to infrastructure, then results flow back up to the terminal. See Request flow for the trace.
